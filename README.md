# 🪙 Coinflip Rigger

A coinflip analysis tool that uses the available server hash and seed information to predict which side should be chosen.

## ⚡ Features

* 🔐 Displays the **Server Hash**
* 🌱 Displays the **Server Seed**
* 🎯 Predicts which side to choose
* 📊 **~95% tested accuracy**
* ⚡ Fast and lightweight
* 🖥️ Simple output that's easy to understand

## 📈 Accuracy

Based on testing, the tool has achieved approximately **95% accuracy** in predicting the coinflip outcome.

> **Tested Accuracy: ~95%**

Actual results may vary depending on the coinflip system, implementation, and available data.

## 🔍 How It Works

The tool analyzes the server hash and seed used by the coinflip system. It processes this information to determine the predicted outcome and displays the recommended side to choose.

Example:

```text
Server Hash: xxxxxxxxxxxxx
Server Seed: xxxxxxxxxxxxx

Predicted Side: HEADS
Accuracy: ~95%
```
